# Jaipur Online

بازی دو نفره آنلاین Jaipur — React/Vite در سمت کاربر و Cloudflare Workers + Durable Objects + D1 در سمت سرور.

## امکانات نسخه ۲

- **تایمر نوبت (سمت سرور):** هر نوبت ۶۰ ثانیه (قابل تنظیم با متغیر `TURN_SECONDS`). اگر زمان تمام شود نوبت بازیکن می‌سوزد و نوبت به حریف می‌رسد.
  اگر یک بازیکن **۳ نوبت پشت‌سرهم** را از دست بدهد، بازی را می‌بازد (Forfeit). هر حرکت واقعی شمارنده را صفر می‌کند.
  تایمر با Durable Object Alarm اجرا می‌شود؛ پس حتی اگر هیچ کلاینتی پیام نفرستد هم درست کار می‌کند و قابل تقلب نیست.
  اگر هر دو بازیکن آفلاین شوند ساعت متوقف می‌شود و با بازگشت یکی از آن‌ها ادامه پیدا می‌کند.
- **جلوه‌های بصری:** نور و پرتو متحرک، فانوس‌های شناور، گرد و غبار طلایی، نورافکن دنبال‌کننده ماوس، درخشش لبه کارت ورود،
  حلقه و فیوز تایمر (زرد → نارنجی → قرمز با تیک‌تاک صوتی)، انفجار سکه هنگام فروش، تابش گرم هنگام نوبت شما.
- **صفحه ورود/ثبت‌نام جدید:** تب متحرک، نمایش/مخفی کردن رمز، هشدار Caps Lock، نوار قدرت رمز، فونت فارسی (وزیرمتن).
- **پاداش بازی:** برنده ۵۰ سکه و بازنده ۱۰ سکه می‌گیرد (ثبت اتمیک همراه تاریخچه). ادمین از ربات می‌تواند موجودی را تغییر دهد.
- **دیتابیس خودترمیم:** جدول‌ها در اولین درخواست خودکار ساخته می‌شوند (`worker/schema.ts`).
- **`/api/health?deep=1`:** بررسی سلامت Worker، D1 و Secret (بدون نمایش مقدار Secret).
- رفع باگ: بعد از ری‌استارت Durable Object، ایندکس کاربر/اتاق دوباره ساخته می‌شود؛ خطای نوشتن تاریخچه دیگر بازی زنده را خراب نمی‌کند؛ خطاهای TypeScript در `worker/auth.ts`.

## ساختار

- `client/` رابط React (ورود، لابی، بازی)
- `server/` موتور بازی و مدیریت اتاق (خالص و تست‌شده)
- `shared/` نوع‌ها و قوانین مشترک
- `worker/` Worker اصلی + Durable Object + احراز هویت + `schema.ts`
- `db/` اسکریپت SQL (اختیاری؛ Worker خودش جدول‌ها را می‌سازد)
- `wrangler.jsonc` تنظیمات Cloudflare

## دیپلوی

راهنمای قدم‌به‌قدم و رفع خطا: **[DEPLOY-CHECKLIST.md](./DEPLOY-CHECKLIST.md)**

خلاصه: `database_id` درست در `wrangler.jsonc` → Push در GitHub → بعد از دیپلوی Secret با نام `ADMIN_API_TOKEN` را اضافه کن → `/api/health?deep=1` را باز کن.

## اجرای محلی

Node.js 22.18 یا بالاتر:

```bash
npm install
npm test            # ۳۳ تست موتور بازی، اتاق‌ها و تایمر
npm run typecheck
npm run build
npx wrangler dev --port 8787 --var ADMIN_API_TOKEN:dev --var TURN_SECONDS:15
```

## محدودیت‌های پلن رایگان

Workers Free: ۱۰۰٬۰۰۰ درخواست در روز. D1 Free: ۵ میلیون خواندن و ۱۰۰ هزار نوشتن در روز. Durable Objects (SQLite) روی Free در دسترس است.
هر بازی چند ده نوشتن بیشتر مصرف نمی‌کند؛ برای صدها بازی در روز کافی است.

## امنیت

رمز عبور با PBKDF2-SHA256 و Salt ذخیره می‌شود، Session با کوکی HttpOnly است و Backup ربات شامل Hash رمزهاست
(فایل Backup را محرمانه نگه دار). فایل‌های `.dev.vars` و `.env` را Commit نکن.
